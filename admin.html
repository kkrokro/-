⚡ Supabase Setup Instructions
  1. Go to supabase.com and create a free project.
  2. In the SQL Editor, run: CREATE TABLE rooms (id SERIAL PRIMARY KEY, name TEXT NOT NULL, description TEXT, price NUMERIC NOT NULL, image_url TEXT, available BOOLEAN DEFAULT true);
  3. Enable Realtime on the rooms table under Database → Replication.
  4. Copy your Project URL and anon key from Settings → API.
  5. Paste them into main.js at the top (SUPABASE_URL and SUPABASE_ANON).
  6. All changes here will reflect instantly on the website.
